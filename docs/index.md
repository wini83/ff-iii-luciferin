# ff-iii-luciferin

`ff-iii-luciferin` provides an async Firefly III client and simplified Python
models for transactions and categories. It can retrieve transactions, read
system information, and update selected transaction fields. Its small matching
helper compares a transaction's date and absolute amount with candidate items.

Start with [Getting started](getting-started.md), then read
[Transactions and matching](transactions.md) for the mapping and matching
rules. The [API reference](reference/client.md) documents the handwritten
surface. The generated OpenAPI transport package is an implementation detail
and is intentionally excluded.
